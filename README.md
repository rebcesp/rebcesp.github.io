# rebcesp.github.io
Personal Blog

## Ejecutar en local

Requiere Ruby 3.x con DevKit (en Windows: `winget install RubyInstallerTeam.RubyWithDevKit.3.3`).

```bash
cd rebcesp.github.io-master
bundle install
bundle exec jekyll serve
```

El sitio queda disponible en http://127.0.0.1:4000 y se regenera solo al guardar cambios.
